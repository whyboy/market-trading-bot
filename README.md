# market-trading-bot

Python 多策略交易项目，先实现 ETF 动量轮动模拟盘，预留实盘执行接口。当前支持行情获取与手动信号预览；模拟成交、CSV账本、定时任务及推送尚未实现。

│   └── etf_rotation_strategy.json  # 策略参数、运行实例、资金、费用、调度
├── src/

│       │   ├── base.py             # 策略接口：行情与账户快照 → 目标持仓

## 运行边界

- 策略只输出目标持仓；执行器负责买卖数量、资金与交易限制检查、委托及成交。订单与成交分别记录，为实盘未成交、部分成交及撤单保留空间。
- 一个策略配置可声明多个运行实例；实例通过唯一 `id` 与 `mode` 区分模拟盘和实盘，各自维护独立账本。新增策略增加策略模块与JSON配置。
- 行情缓存可共享；资金、持仓和收益不可跨实例混用。多个策略共用实盘账户的资金分配与订单汇总暂不实现。
- 数据按 `data/<instance_id>/` 保存 `signals.csv`、`orders.csv`、`fills.csv`、`positions.csv`、`equity.csv`、`runs.csv`；报告按 `reports/<instance_id>/` 保存。CSV由单进程协调写入，记录运行状态并防止同一任务重复成交。

## ETF策略口径

- A股交易日北京时间14:30计算并模拟调仓，15:15按收盘价生成日报；收益从账户启动日累计，不补历史回测。
- 动量采用24个历史交易日收盘价加当日14:30价格，共25点；沿用原策略加权对数价格回归及年化收益×拟合优度评分。
- 波动率采用19个历史交易日收盘价加当日14:30价格，共20点、19个对数收益；样本标准差按250日年化。
- 选择动量第一名，即使全部得分为负；目标仓位为目标波动率÷标的波动率，限制在0至100%，极低波动率时为100%。标的不变也按目标仓位调仓。
- 默认初始空仓、资金10万元、双边佣金万二、单笔最低5元、零滑点；通过配置调整。成交按盘中行情模拟，份额与可卖数量遵循标的交易限制。
- 日报展示模拟操作、收盘持仓、当日及累计收益和简单收益曲线。行情失败时不得伪造成交；推送失败不得重新执行交易。

## 配置

在 `config/global.json` 中集中配置行情源与PushPlus Token；仓库中的Token保持为空，真实Token仅在服务器填写，不提交。行情使用AKShare东方财富接口，图片服务和券商适配待后续确定，`null`表示尚未选择。

策略配置中的 `instances` 支持同策略多实例；第一版仅启用 `pap`。未来增加 `pro` 实例及对应券商执行器。金额、费率、滑点、策略参数和执行时间均使用JSON配置，不使用环境配置文件。

## 手动预览

Python 3.12+，在仓库根目录执行：

```bash
python -m venv .venv
.venv/bin/python -m pip install -r requirements.txt
.venv/bin/python main.py --at 2026-11-20T14:30:00
```

`--at`指定北京时间行情截止分钟；省略时使用当前分钟。`--config`可指定策略JSON，路径相对仓库根目录。命令仅输出JSON：行情源、信号时间、各ETF报价及报价时间、历史区间、评分、波动率和目标权重；不下单、不写账户、不生成收益。

- 日线使用前复权价，分钟线使用未复权价；仅取当日前的完整日线和不晚于截止时刻的分钟价格。默认允许分钟行情滞后最多60秒。
- 交易日历来自新浪，验证日期覆盖和历史交易日连续性；非交易日、非连续交易时段、未来时刻、价格无效、历史不足或行情过期均停止，退出码为1。
- [AKShare接口文档](https://akshare.akfamily.xyz/data/fund/fund_public.html)说明1分钟数据仅覆盖近期5个交易日。`--at`用于近期信号核对，不提供历史回测；前复权历史随数据源更新，不保证历史时点复权因子可重现。
- 免费行情有延迟与限流风险。请求超时和间隔在全局配置中调整；失败直接停止，不自动重试或替换数据源。当前服务器已验证日线、分钟线及交易日历接口，但四标的完整在线预览因东财IP限流尚未验证通过。
